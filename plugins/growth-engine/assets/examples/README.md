# Worked examples

Two complete reference founders, one per track. Every file the plugin produces, filled in properly.

| Folder | Founder | Track | Business |
|---|---|---|---|
| `b2b-northfield/` | Sam Okoye | B2B | Northfield Ops, fractional operations for construction SMEs |
| `b2c-lumen/` | Priya Raman | B2C | Lumen Skin, a three-product skincare line sold on Instagram |

## What these are for

Founders read these to see what "finished" looks like before they build their own. Not to copy the content, which is specific to a fictional business, but to calibrate depth, tone and format.

Mentors use them to mark gate submissions against a real standard rather than a description of one.

## How they were made

By running the plugin end to end as each fictional founder. Not written by hand. If a skill changes, regenerate the affected example rather than editing it, or the example stops reflecting what founders will actually get.

## Rule

These stay fictional. No real customer names, no real prospect data, no real numbers from any Oneday founder.
