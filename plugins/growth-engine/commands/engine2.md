description: Build your outreach engine (B2B) or audience engine (B2C)
---

Read `./growth-engine/founder-brain.md` and check the `track` field.

If track is `b2b`, use the outreach-b2b skill.
If track is `b2c`, use the audience-b2c skill.
If the Brain does not exist, stop and tell the founder to run `/brain`.

Do not ask the founder which track they are on. It is already recorded.
